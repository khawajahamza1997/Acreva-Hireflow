- [ ] `RESEND_API_KEY` + `EMAIL_FROM` + `RESEND_TEST_TO_EMAIL` set (real email works)

## Master screen recording (one session)

Record **each beat as a separate clip** (easier to edit in Canva).  
Target: **~3 minutes raw** → cut to **2 min (clients)** / **60 sec (social)** / **50 sec (Fiverr)**.

### Recording software (Windows)

| Tool | Best for |
|------|----------|
| **OBS Studio** | 1080p screen, optional webcam corner |
| **Xbox Game Bar** (`Win + G`) | Quick clips, no install |

**OBS:** Canvas **1920×1080**, 30 fps, MP4 → save to `video/raw/option-c/`

### Recording rules

1. Move mouse **slowly**; pause **2 seconds** after every success banner  
2. Do **not** scroll fast — viewers need to read scores and names  
3. Record **two takes** of clips **6 (Outreach)** and **7 (Gmail)**  
4. Keep cursor away from personal emails in Gmail sidebar

## Troubleshooting on recording day

| Problem | Fix |
|---------|-----|
| Placeholders in email | Select Sarah again; wait for auto-fill; or click **Fill template for candidate** |
| Email not sent | Check Render `RESEND_*` env vars; use test inbox from Outreach banner |
| Scoring 0 / error | `OPENAI_API_KEY` on Render; redeploy |
| Gmail clip looks cluttered | Zoom crop to email body only; hide sidebar in Gmail settings temporarily |
| Fiverr rejects video | Shorten to 45–55s; more face time; remove any URL/email from frame |
