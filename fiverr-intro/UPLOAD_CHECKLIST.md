# Fiverr Upload Checklist

## File to upload

`fiverr-intro/export/acreva-intro.mp4`

---

## Pre-upload checks

- [ ] Length: 20–60 seconds (target 45–55)
- [ ] You visible and speaking in first ~12s and last ~10s
- [ ] English audio with subtitles
- [ ] Resolution: at least 1280×720, 16:9 landscape
- [ ] Format: MP4 (H.264 + AAC)
- [ ] Filename: simple ASCII, e.g. `acreva-intro.mp4`
- [ ] No email, phone, WhatsApp, or social links anywhere in frame
- [ ] No Fiverr badges or level graphics

---

## Upload steps

1. Log in to Fiverr as **acreva**
2. Go to: https://fiverr.com/sellers/acreva/edit?focused_section=intro_video
3. Scroll to **Intro video**
4. Click **Upload** → select `acreva-intro.mp4`
5. Wait for processing (may take a few minutes)
6. Submit for review

---

## If rejected

| Issue | Fix |
|-------|-----|
| Too short / too long | Re-export between 45–55s in CapCut |
| Seller not visible | Add more face footage at start and end |
| Poor audio | Re-record in quiet room; use USB mic |
| Contact info detected | Remove text overlays or re-shoot |
| Wrong format | Re-encode with HandBrake (720p30 MP4) |
| Not English | Add subtitles or re-record in English |

---

## After approval

- Profile strength should increase (toward 10/12)
- Preview: https://fiverr.com/sellers/acreva
- Optional later: add 60–75s Gig videos per service, reusing screen clips

Moderation usually takes a few hours to 1–2 business days.
